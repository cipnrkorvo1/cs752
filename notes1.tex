	\section{Brute Force Classification}
	\subsection{Supervised Machine Learning}
	\begin{outline}
		\1 Input space $X$, Output space $Y$
		\1 Training data: given many instances $\mathcal{D} = \{(\vec{x}_i, y_i)\}^N_{i=1}$
		\1 Learn a function $X \rightarrow Y$ which is expressed by parameters
		\1 Test data: Given new $\vec{x}_{N+1}$, use function to predict $y_{N+1}$
		\1 Evaluation: Check whether prediction $y_{N+1}$ matches the ground truth $y^*_{N+1}$
		\1 $y^*_{N+1}$ is not known to the black box (held-out)
	\end{outline}
	\subsection{Text Categorization}
	\begin{outline}
		\1 Given a text document, assign it to one of $K$ categories.
		\1 Consider how you're deciding the category and how you would explain it to the computer.
		\1 Input space: documents, Output: one of $K$ categories
		\1 Training data: documents and their category (e.g. sports, news)
		\1 Learn a categorization function
		\1 Test data: Given a new document, use function to predict category
		\1 Evaluation: Check whether predicted category is correct
		\1 Evaluation measure: how many correct predictions?
	\end{outline}
	\subsubsection{Binary Text Categorization Task}
	\begin{outline}
		\1 There is only one category.
		\1 Predict whether the document is in the category or not (pos/neg)
		\1 Same: Predict the set of documents that are in this category.
		\1 Input space: documents, Output: $\{0, 1\}$ (1=positive)
		\1 Training data: documents and whether they are in this category (e.g. sports or not)
		\1 Learn a categorization function
		\1 Evaluation measure: how many correct predictions?
	\end{outline}
	\subsubsection{One-vs-Rest Classification}
	\begin{outline}
		\1 Input space: documents, Output: one of $K$ categories
		\1 Redefine the task to learn $K$ binary categorization functions
		\1 Learn $K$ categorization functions (one per category)
		\1 Can a document be positive for multiple categories? If yes, which category to choose?
		\2 Each categorization function bases the decision on a \textbf{Classification Score} or \textbf{Confidence}
		\2 Assign the document to the category with the highest confidence
	\end{outline}
	\subsubsection{Supervised Document Classification}
	\begin{outline}
		\1 Represent documents with feature vectors
		\1 Example content features:
			\2 $f_1{d}:$ 1 if doc $d$ contains the word "ball"; 0 otherwise
			\2 $f_2(d):$ 1 if doc $d$ contains the world "goal"; 0 otherwise
			\2 $f_3(d):$ 1 if doc $d$ contains the word "election"; 0 otherwise
		\1 Change the parameters in the function to get more predictions right
		\1 Iteratively update parameters (Training loop)
		\1 Then fix the parameters, make one prediction in the test set
		\1 Sometimes: very good on the train set, but errors on the test set
		\1 {\bf Note: Never train on the test data!}
			\2 Never test on the training data (unless you call it training error)
			\2 Never leak the test data into your training process
	\end{outline}
	\subsection{A Simple Categorization Model}
	\subsubsection{Linear Hyperplane Model}
	\begin{outline}
		\1 Feature vectors in space $X$ (number of features = dimension of space)
		\1 Find a hyperplane that separates positive from negative examples
		\1 To classify a new example, see if it is on the "positive" side of the hyperplane
			\2 Weight vector $\vec{w}$ points towards positive side
		\1 {\it The hyperplane has one fewer dimension than the vector space}
	\end{outline}
	\subsubsection{Hyperplane Parameters}
	\begin{outline}
		\1 Hyperplane is represented by vector $\vec{w}$
		\1 $\vec{w}$ is orthogonal to the hyperplane
		\1 $\vec{w}$ has the same dimensionality as $\vec{x}_i$
		\1 If $\vec{w} \cdot \vec{x}_i > 0$ then example $i$ is positive
		\1 Inner product $\vec{w} \cdot \vec{x}_i = \sum_jw_jx_{ij}$ over feature dimensions $j$.
	\end{outline}
	\subsubsection{Inner Products and Cosines}
	\begin{outline}
		\1 If $\vec{w} \cdot \vec{x} > 0$ then example $i$ is positive
		\1 Same as: $\angle(\vec{w}, \vec{x}_i) < 90\deg$
		\1 Same as: $\cos(\vec{w}, \vec{x}_i) > 0$ \hspace{3em}$\cos(\vec{a}, \vec{b}) = \frac{\vec{a} \cdot \vec{b}}{||\vec{a}||\:||\vec{b}||}$
	\end{outline}
	\subsubsection{Hard vs Soft Classification}
	\begin{outline}
		\1 Sometimes we want to tolerate classification errors in training data to get a more robust hyperplane
		\1 We don't want outliers and errors to dictate our model.
		\1 \textbf{Hard classification} is strict; the hyperplane exactly and entirely divides the space into positive and negative
		\1 \textbf{Soft classification} allows for some errors, typically to allow for a simpler hyperplane. This also prevents outliers and errors from causing issues with classification
	\end{outline}
	\subsection{The Intercept of the Model}
	\subsubsection{Changing the Threshold with "The Intercept"}
	\begin{outline}
		\1 Changing the threshold $b$: $\vec{w} \cdot \vec{x}_1 > b$ \hspace{2em} The intercept $b$
		\1 By adjusting $b$, you shift the threshold of classification.
		\1 \textbf{Intercept trick:} It is easy to forget to add the intercept for $\vec{w} \cdot \vec{x}_i > b$.
		\2 Rewrite as $\vec{w} \cdot \vec{x}_i + (-b)\cdot 1 > 0$, recognize the inner products
		\2 Consider the feature vector $\vec{x}_i$ with $D$ dimensions. Append one additional feature dimension as follows:
		\begin{equation*}
			\vec{x}_i =
			\begin{pmatrix} x_{i1} \\ x_{i2} \\ ... \\ x_{iD} \\ 1 
			\end{pmatrix} 
			\hspace{70pt}
			\vec{w} = 
			\begin{pmatrix} w_1 \\ w_2 \\ ... \\ w_D \\ -b
			\end{pmatrix}
		\end{equation*}
		\2 Train a classification model on augmented $\vec{x}$ without intercept:
		\3 Classify: If $\vec{w} \cdot \vec{x}_i > 0$ then $i$ is positive
		\2 Automatically learns the intercept as $w_{D+1} = -b$
		\1 \textbf{Note:} For the rest of the course, we will use the intercept trick. Whenever you load features $x_i$, \underline{don't forget to add another 1 as a constant feature.}
	\end{outline}
	\subsection{Training -- Coordinate Ascent}
	If $\vec{w} \cdot \vec{x}_i > 0$ then example $i$ is positive.
	\begin{outline}
		\1 Start with an initial $\vec{w}$, which can be vector of zeros or random.
		\1 Repeat: Randomly select a dimension $j$ (coordinate)
		\2 Vary the entry $w_j$ up or down, observe classification quality
		\2 Lock in the best setting for $w_j$
		\2 Move onto next dimension...
		\1 Keep on repeating until the change in quality is small
		\hspace{1em}
		\1 To "Vary $w_j$": use a grid of values $\Delta_k$ to try out, e.g.
		\begin{equation*}
			\begin{pmatrix}w_1\\...\\w_j\\...\\w_{D+1}\end{pmatrix}
			\rightarrow
			\begin{pmatrix}w_1\\...\\w_j + \Delta_1\\...\\w_{D+1}\end{pmatrix}
			\rightarrow
			\begin{pmatrix}w_1\\...\\w_j+\Delta_2\\...\\w_{D+1}\end{pmatrix}
			\rightarrow
			...
		\end{equation*}
		\1 Use each $\vec{w}$ to classify all training examples, choose $\vec{w}$ with the best prediction quality (before advancing to next $j$).
		\1 \textbf{When to stop?:} Since changing $w_1$ will affect the best choice for $w_2$, etc. we have to consider the same coordinate $j$ multiple times.
		\1 There might always be a tiny improvement, loop forever...
		\1 Run until the relative improvement in quality is small. How to measure quality? $\rightarrow$
	\end{outline}
	\subsection{How to measure Prediction Quality?}
	\begin{outline}
		\1 "choose $\vec{w}$ with the best \underline{prediction quality}"
		\1 \textbf{Accuracy:} how many examples $i$ are correctly predicted (higher is better)
		\1 \textbf{Misclassification rate:} fraction of mistakes (lower is better)
		\1 We can easily use other measures of prediction quality
		\2 \textbf{Precision:} among all $i$ that are predicted as positive, how many are correct?
		\2 \textbf{Recall:} of all actually positive $i$, how many are predicted as positive?
		\2 \textbf{F1-Measure:} harmonic mean of precision and recall
		\begin{equation*}
			\text{F}_1\text{ score } = 2 \cdot \frac{\text{Precision}\cdot \text{Recall}}{\text{Precision} + \text{Recall}} 
		\end{equation*}
		\2 Others:
		\3 ROC-AUC ("Area under the Receiver-Operator Curve")
		\3 For ranking problems: MAP, NDCG, Precision-at-R, Utility
	\end{outline}
	\subsubsection{Confusion Matrix}
	\begin{outline}
		\1 For binary classification, Precision, Recall, F1, Accuracy are based on the \textbf{confusion matrix}.
		\2 $S = \{\text{$i$ that are predicted as positive}\}$
		\2 $S^* = \{\text{$i$ that are actually positive}\}$
		\2 $U$: Set of all instances $i$.
	\end{outline}

	\subsection{Coordinate Ascent with Features and Z-Score Normalization}
	\subsubsection{Coordinate Ascent Recap/Recontextualize}
	Start with a random $\vec{w}^{(0)}$ (\textbf{initialization}).\\
	Iterate many times (for $t$ in $1...$): (\textbf{outer loop})
	\begin{outline}
		\1 Randomly select a dimension $j$ (\textbf{coordinate})
		\2 For every $\Delta_k$ on the grid: (\textbf{inner loop})
		\3 Temporary vector $\tilde{\vec{w}}_{jk} = \vec{w}^{(t-1)} + \Delta_k\vec{1}_j$
		\3 Note: $\vec{1}_j = (0,...,0,1,0,...)$ is the \textbf{unit vector} for coordinate $j$
		\3 \textbf{Prediction quality} $\tilde{O}_k =$ classification quality when using $\tilde{\vec{w}}_{jk}$.
		\2 Identify \textbf{best step size} $k_{\text{best}} =$ arg $\text{max}_k \tilde{O}_k$
		\2 \textbf{Update the weight vector} $\vec{w}^{(t)} = \tilde{\vec{w}}_{jk_{\text{best}}}$
		\2 \textbf{Quality of iteration} $t$ is $O^{(t)} = \tilde(O)_{k_{\text{best}}}$
	\end{outline}
	Keep on iterating until the relative change in quality $O$ is small.
	\begin{outline}
		\1 E.g.: Define convergence as improvement over previous 100 iterations
		\begin{equation*}
			1 - \frac{O^{t - 100}}{O^{(t)}} < 0.01
		\end{equation*}	
		\1 Stop iteration when converged (maybe plot convergence over $t$)
	\end{outline}
	Will the quality $O$ always improve over time?\\
	Yes! Well: it will never decrease (if you include step size $\Delta_{\text{stay}} = 0$).

	\subsubsection{Z-Score Normalization}
	Z-Score normalization re-centers the feature vectors so that they have the same mean and variance. The grid needs to be chosen to explore the range of the distribution.
	\begin{outline}
		\1 We transform all feature vectors, so that
		\2 mean $\mu_j$ across examples $\vec{x}_i$ will be zero
		\2 the standard deviation $\sigma_j$ across examples $\vec{x}_i$ will be one
		\1 This is called an \textbf{isotropic Gaussian distribution} $\mathcal{N}(0,1)$
		\1 For each feature $j$:
		\2 compute its mean $\mu_j$ across examples $\vec{x}_i$ (using only $j$'th entries)
		\2 compute its standard deviation $\sigma_j$ across examples $\vec{x}_i$
		\1 Transform all features of all feature vectors $\vec{x}_i$ via
		\begin{equation*}
			x_{ij} := \frac{x_{ij} - \mu_j}{\sigma_j}
		\end{equation*}
	\end{outline}
	\subsubsection{Term-Frequency Inverse-Document-Frequency (TF IDF)}
	\begin{outline}
		\1 Represent all documents $d_i$ in a corpus
		\1 Vector space $\mathfrak{F} = \mathcal{R}^V$: one dimension per word type ("ball")
		\1[]
		\1 Term Frequency: $\text{tf}_{j,i}$ is how often word $j$ appears in doc $d_i$.
		\1 The $j$'th entry of document feature $\vec{x}_i = x_{ij}$ is
		\begin{align*}
			& x_{ij} = \underbrace{\log(1 + \text{tf}_{j,i})}_{\text{TF}} \cdot \underbrace{\log(\frac{\text{tf}_{*,*}}{1 + \text{tf}_{j,*}})}_{\text{IDF}} && \\
			& \text{tf}_{j,*} = \Sigma_{\text{docs } i'} \text{ tf}_{j,i'} && \\
			& \text{tf}_{*,*} = \Sigma_{\text{words } j'} \Sigma_{\text{docs } i'} \text{ tf}_{j',i'} &&
		\end{align*}
	\end{outline}
